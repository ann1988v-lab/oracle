# ORAKUL STORE 🔮

Telegram-магазин цифровых товаров на базе aiogram 3 + SQLite.

## Что уже есть

- Главное меню с отдельной картинкой (`media/main.jpg`), которую можно заменить.
- Отдельные картинки для каталога, профиля, баланса и админ-панели.
- Категории товаров.
- Товар может выдаваться как **Telegram-файл** или как **ссылка** (идеально для GitHub Pages).
- Рублёвый баланс пользователя.
- Пополнение баланса через Telegram Payments в RUB.
- Покупка товара с атомарным списанием средств.
- Мгновенная выдача файла/ссылки после покупки.
- Админка прямо внутри Telegram.
- Список пользователей и просмотр информации/действий.
- Изменение баланса пользователя администратором.
- Добавление, редактирование, скрытие и публикация товаров.
- Добавление и включение/скрытие категорий.
- При добавлении товара администратор задаёт название, описание, цену, категорию и способ выдачи.

## Переменные окружения

```env
BOT_TOKEN=токен_бота
ADMIN_IDS=123456789,987654321
PAYMENT_PROVIDER_TOKEN=токен_платёжного_провайдера
SUPPORT_URL=https://t.me/username
PORT=3000
HOST=0.0.0.0
DATA_DIR=/app/data
```

`PAYMENT_PROVIDER_TOKEN` нужен только для пополнения через Telegram Payments. Если он не задан, магазин всё равно работает, а администратор может вручную менять баланс пользователей.

## Как добавить товар

1. `/admin` → **➕ Добавить товар**.
2. Название.
3. Описание.
4. Цена в рублях.
5. Выбрать существующую категорию или создать новую.
6. Выбрать `Telegram-файл` или `Ссылка`.
7. Отправить файл или URL.

Для GitHub Pages выбирай **Ссылка** и указывай URL опубликованного сайта.

## Важно про цифровые материалы

В каталоге есть демонстрационные карточки для примера. Они создаются скрытыми, пока администратор не добавит реальный файл/ссылку.
Распространяй только материалы, на которые у магазина есть право продажи/распространения. Для игровых ключей используй легально приобретённые ключи.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

Существующая `sakura18.db` сохранена в проекте: код добавляет новые таблицы и поле рублёвого баланса при запуске, не ломая старых пользователей.
